СПОСОБ 1 — через командную строку (самый надёжный)
──────────────────────────────────────────────────

1. Нажмите клавиши Win + R
2. Введите:  cmd
3. Нажмите Enter — откроется чёрное окно

4. Скопируйте и вставьте (ПКМ в окне) СВОЙ путь к папке SG.
   Пример:

   cd /d C:\Users\Иван\Downloads\SG

   Нажмите Enter.

5. Проверка Python (вставьте по одной строке):

   python --version

   Если ошибка — попробуйте:

   py -3 --version

6. Проверка Node:

   node --version
   npm --version

7. Запуск BACKEND (первое окно — не закрывайте):

   cd backend
   pip install -r requirements.txt
   set PYTHONPATH=.
   python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

   Если "python" не найден, вместо последней строки:

   py -3 -m uvicorn app.main:app --host 127.0.0.1 --port 8000

   Должно появиться: Uvicorn running on http://127.0.0.1:8000

8. Откройте ВТОРОЕ окно cmd (Win+R → cmd) и:

   cd /d C:\Users\Иван\Downloads\SG\frontend
   npm install
   npm run dev

   Должно появиться: Local: http://localhost:5173/

9. Браузер → адресная строка:

   http://localhost:5173


СПОСОБ 2 — если .bat не запускается двойным кликом
──────────────────────────────────────────────────

1. Правой кнопкой по файлу check-system.bat
2. «Открыть с помощью» → «Командная строка» или «cmd»
   Или: «Показать дополнительные параметры» → «Запуск от имени администратора»

3. После check-system.bat откроется Блокнот с файлом check-result.txt
   — пришлите его содержимое или скрин


СПОСОБ 3 — PowerShell
─────────────────────

Win+X → «Терминал» или «Windows PowerShell»

cd C:\путь\к\SG
python --version
node --version
